Metadata Lens: quality and knowledge graph for research metadata

Research data project, 2026, rebuilt every week from live repository data

Harvests real publication metadata from the JuSER (Forschungszentrum Jülich) and KITopen repositories over OAI-PMH, checks it against the OpenAIRE guidelines, maps it to Schema.org and DCAT and builds an RDF knowledge graph that you can query with SPARQL directly in the browser.

  • Polite OAI-PMH harvester with resumption tokens; 17 quality rules for identifiers, access rights, licences, dates and languages, each with a severity and a score
  • Semi-automatic curation: proposed fixes such as ISO dates and canonical licence URIs, duplicate detection and publisher spellings, accepted or rejected by a person and exported as JSON
  • Weekly GitHub Actions pipeline and an Airflow DAG; Next.js and TypeScript app with Oxigraph (WebAssembly) for SPARQL; tests for the pipeline and every example query

Python, OAI-PMH, Dublin Core, Schema.org, DCAT, RDF, SPARQL, Next.js, TypeScript, Airflow

Range Atlas: species distribution maps from open biodiversity data

Research data project, 2026, rebuilt every week from GBIF and OBIS

Maps where ten European grasshoppers and crickets, and two marine species, have been recorded since 2000 and models where the climate suits them. Every step from the raw records to the map is visible: quality checks, model scores, run history and the data itself.

  • Darwin Core records from the GBIF and OBIS APIs in a Parquet lakehouse (local or S3); quality checks in DuckDB SQL; WorldClim predictors attached with Dask
  • GLM and Random Forest against a target-group background, scored with spatial block cross-validation; response curves and predictor importance per species
  • FastAPI on PostGIS with vector tiles (ST_AsMVT, cached, ETags) and model runs locally or on AWS Batch; React, TypeScript and MapLibre app with DuckDB in the browser; tests in CI, weekly GitHub Actions rebuild

Python, DuckDB, Parquet, Dask, scikit-learn, PostgreSQL/PostGIS, FastAPI, React, TypeScript, MapLibre, Docker, AWS (S3, Batch)

Whose Inference?

Research pilot, natural language processing

The same sentence means different things to different readers. This pilot predicts how a specific reader will interpret a statistical statement from a personal knowledge base of what they know and believe, rewrites the statement so it is not misread, and looks inside a language model to see how it uses that knowledge.

  • Knowledge-graph retrieval raises reader-prediction accuracy from 42% to 61% (75% with GPT-4o)
  • RSA-style cooperative rephrasing with a simulated listener
  • Activation patching and steering on Qwen2.5-0.5B

LLMs, knowledge graphs, Rational Speech Acts, interpretability, PyTorch
